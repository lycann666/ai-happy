A tiny robot offers a big sunflower to a happy kitten at golden hour — drawn entirely in code, pure Python standard library, no image files. A warm little moment of kindness, with a butterfly, soft clouds, and a "for you" for the judge.

## Run it

```sh
python3 main.py
```

Writes one deterministic 512×512 PNG to `/output/entry.png` (override the output directory with `MAKEFUN_OUTPUT_DIR`). Runs in about 2.5 seconds, standard library only, no network. Running it twice produces byte-identical output.
